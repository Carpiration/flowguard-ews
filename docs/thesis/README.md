# Пояснительная записка

- `Диплом_FlowGuard.docx` — собранный документ.
- `src/*.txt` — текст по главам в простой разметке (описана в начале `build.py`), `src/refs.txt` — источники.
- `img/` — рисунки: скриншоты приложения и схемы (`tools/figs.py` строит схемы и графики по `docs/experiments/results.json`).
- Сборка: `bash tools/make.sh` (нужны python-docx, LibreOffice и poppler). Скрипт собирает документ, проставляет номера страниц в оглавлении и создаёт `out/`.
- `python3 tools/check_tables.py` проверяет, что таблицы не разрываются между страницами.

Оформление снято с эталонного документа кафедры: поля 3/1,5/2/2 см, Times New Roman 14, интервал 1,5, абзацный отступ 1,25 см, таблицы 11,5 пт, номера страниц с введения.

Презентация: `../presentation/Презентация_FlowGuard.pptx`, её содержание — в `../presentation/deck.py`.
